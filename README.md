# Fintech Mobile App UI

A sleek, modern frontend user interface designed for a mobile banking application. This project showcases a clean, intuitive layout focused on delivering a smooth digital banking user experience without any backend dependencies.

## Key Features

* **Account Dashboard:** Real-time summary layout displaying balances, quick navigation, and recent activity.
* **Seamless Money Transfers:** Streamlined flow for moving funds between accounts and beneficiaries.
* **Bill Payments & Utility Management:** Dedicated views for utility bills, subscriptions, and recurring payments.
* **Security & Authentication Screens:** Clean UI designs for user login, PIN entry, and biometric verification.

## Tech Stack

* **HTML5:** Semantic structure for optimal accessibility and responsive design.
* **CSS3 / Styling:** Custom styling, layout flexbox/grid system, and smooth transitions.
* **JavaScript:** Interactive UI components and client-side view routing.
